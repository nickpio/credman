# Superseded operation-broker proposal

This folder preserves the first design and its source/format checks. The user subsequently clarified that Credman should be a credential vault for agents to store credentials from authorized signups and share credential access with other agents.

The current proposal is [the agent credential vault](../../README.md). This archive is not the current product recommendation. Its authenticated-identity, non-disclosure-limit and source-code observations remain useful, but its typed-provider-operation MVP and no-secret-read surface were superseded.

`design-verification.json` is a historical check of the pre-archive files at their original paths. It is not verification of the revised design or implemented behavior. No implementation was performed for either proposal.
